### 1.1 奇门局数（`#25–#30`）——**拆补为默认，符头（超神接气置闰）并列**

**核实状态：逐格对拍通过。** 二十四节气三元局数表与独立开源实现
[arc119226/qimen_dunjia](https://github.com/arc119226/qimen_dunjia) 的 `constants.js` `JIEQI_JUSHU`
逐格比对一致；该实现自述以《統宗》康熙五十六至五十八年（1717–19）算例 10 个检核点 +
《法竅》〈論拆局補局〉7 个检核点做过回归，并以康熙五十八年立秋正授（1719-08-08）作**外部锚点**。
该表亦与本站 v1 的 `QIMEN_JU` 完全一致（v1 表无错，错在只用其一派）。

采派与依据（`detail.流派` / `detail.定局` / `detail.超接置闸` 逐项写出）：

| 派 | 起局口径 | 依据（`CITE` 键） |
|---|---|---|
| **拆补（默认）** | 节气交接**时刻**起算，0–5 日上元、5–10 日中元、≥10 日下元 | `CITE.法窍拆补`：如遵時憲書節氣为憑，其正授、超神、接氣、置閏不辨而自明矣；`CITE.拆补五日一元` |
| 符头（可选 `params.school:'符头'`） | 符头＝甲己日，三元由符头支定（子午卯酉上 / 寅申巳亥中 / 辰戌丑未下） | `CITE.宝鉴符头为体`：以甲子、己卯、甲午、己酉为符头者……符头为体，节气为用；`CITE.统宗定三元` |
| 置闰（含于符头派） | 置闰**锚定芒种／大雪**；门槛用历日差 ≥ 8（典籍「超九日」为含头计数） | `CITE.演义置闰`：置閏定在芒種、大雪之後。設遇小滿、小雪二氣之交，雖超九日、十日，不可置閏 |

**三元定元闭式（调研 A3b，可用一行算式替代查表）**：`元序 = (六十甲子序 % 15) / 5`（0=上元 1=中元 2=下元）。
三独立源逐项一致（ZhouYiLab `qi_men.cpp:82-84` 逐项验算 12 个符头全中；horosa `SAN_YUAN_FU_TOU`
十二符头集合完全相同，两种机制、同一分组）。本实现以**查表口径**落地（符头支分组），
两者等价 —— 因本实现还需要符头**日**、超神／接气日差等信息，闭式无法单独提供。

**拆补 vs 符头的另一读法（已并陈，未擅自择一）**：调研 A4 记 horosa 的 `chaibu` 档是
「按曆法节气 + **符头元**」、`zhirun` 才是「超神接气链」；而 v1 与 `qimen_dunjia` 的拆补是
「按**交节时刻**起算 5 日一元」。两者是同一名义下的两种口径。本实现的 **`拆补` = 交节时刻起算**
（与 v1、与 `qimen_dunjia` README 的明文一致），**`符头` = 符头体用法**（含置闰），
两派都排得出，读者可对照取用，`detail.定局` 每次写明本次用的是哪一派。

**v1 注释点名的坑（已显式处理）**：「历法库按日切换冬至／夏至顺逆，当日须按下一节气校正」。
v2 的做法是把 `chart.jieqi.prevAt / nextAt` 的**交接时刻**（精确到秒）与占时直接比较：
- **阴阳遁**：`节气环序 < 12` 为阳遁，环序由**交接时刻校正后**的节气取（`jieqiStateOf`）。
- **三元**：拆补法用「占时 − 交接时刻」的毫秒差算天数，故交节当日 `03:00` 与 `06:00` 可落不同元
  （按日粒度的库会把两者归同元，正是 v1 的错源）。
- 若历法库给出的 `prevAt` 竟晚于占时（即占时仍在更上一气内），则退用上一气，并在
  `detail.节气校正` 标注 `已按交接时刻退用 X（当日交节边界校正）`。

**实测**（`2026-02-04 立春 04:02:08` 交节）：

```
2026-02-04 03:00  拆补 → 阳遁6局（大寒·下元，节后 14.72 日）   符头 → 阳遁8局（立春·上元，正授）
2026-02-04 06:00  拆补 → 阳遁8局（立春·上元，节后  0.08 日）   符头 → 阳遁8局（立春·上元，正授）
```
同一天相隔 3 小时即换局，交接时刻确实生效。

### 1.3 六壬九宗门（`#32`、`#40`）——**伏吟/返吟为课体前提，内部仍先取贼克**

**核实状态：判据次序与各分支取法均逐条带 `cite`；已按调研 §B4 订正。**

v2 判据次序（**据 horosa `liureng/ChuangChart.js:191-244`「发三传九法的判定顺序（课经条文口径）」**，
与 ZhouYiLab 的「守卫条件抛异常」机制语义等价 —— 调研自查结论：两者语义完全一致，mingpan 因缺别责而相异）：

```
伏吟 → 返吟 → 贼克（重审/元首）→ 比用（知一）→ 涉害 → 八专 → 遥克（蒿矢/弹射）
      → 别责（芜淫）→ 昴星（兜底）
```

> ⚠ **订正**：任务书与 Lead 转述给的顺序是 `…涉害 → 遥克 → 昴星 → 别责 → 八专`，
> 该序**不是判定序**（是古籍「九法」章的**列举序**）。horosa 源码里有专门的事故复盘：
> 「曾把古籍九法章的列举序号（遥克第 4／八专第 9）误读为判定优先级……列举序≠判定序；
> 判定序只认『八专不取遥、别责须无遥』等条文本身」。本实现已按**判定序**改正：

- **八专必须在遥克之前**：课经「有克照常以克贼比涉论，如无克贼比涉，**不复取遥克**」——
  「遥者远也」，干支同处一位无远可言。本实现的八专分支只处理「两课无克」，有克者已在贼克链返回。
- **八专必须在别责之前**：八专（一课＝三课）会令二课＝四课，从而满足「某两课相同」的别责前提，
  先判别责会被误吞。
- **遥克在别责/昴星之前**：「无遥无克别责例」、昴星须四课全备。
- **昴星是兜底**（四课全备且无克无遥，总会返回）。
- **伏吟/返吟先判**：二者是天地盘的课体前提（月将加时同支／相冲），会同时改写四课的上神结构；
  但**其内部先吃贼克**——有克仍以贼克发用，中末另取（伏吟递取其刑；返吟递传）。
- 涉害四格名（ZhouYiLab `da_liu_ren.cpp:696`）：**涉害卦 / 见机卦（取临四孟）/ 察微卦（四仲四季）/ 复等卦**
  —— 已写进 `detail.取传过程`，每步可读。
- 返吟二格名（ZhouYiLab `:551-554`）：**无依卦**（有克，初中末相冲）／**无亲卦**（无克，取驿马发用、
  中传支上神、末传日上神）—— 与本实现逐项一致。
- 伏吟三格名（ZhouYiLab `:426-428`）：**不虞卦**（四课有贼克）／**自任卦**（无克，刚日）／
  **自信卦**（无克，柔日）—— 与本实现一致。
- 十二天将：贵人起法「甲戊庚牛羊…」（`CITE.贵人歌`），昼夜分卯至申／酉至寅，
  贵人所乘地盘宫在亥子丑寅卯辰顺布、巳午未申酉戌逆布（`CITE.贵人顺逆`）
  —— 与调研 §B5「horosa 与 mingpan 逐字相同」一致。

## 3. 自测证据（可复现）

### 3.1 奇门 `#25 / #26 / #27` 参数确实分化（实测统计，非举例）

以 2026 全年逐时（每 2 小时，**4800 个样本**）对拍转盘与飞盘：

```
不变式「值符落宫 == 时干宫（时干入中时按坤二归一化）」：9600/9600 命中，0 异常  ✅
转盘 vs 飞盘  天盘九星不同 : 77.8%
转盘 vs 飞盘  天盘干不同   : 77.8%
转盘 vs 飞盘  八神盘不同   : 100.0%
转盘 vs 飞盘  值符星名/落宫: 0.0%   ← 这是对的：「值符随时干」是两派共守的锚点，
                                      两法都必落时干宫、取同一值符星（调研 A6 双源一致）
```

**转盘的两种布法与一条历史教训**：本模块早期把飞盘写成「八宫环上转同一量」——
而 **8 元环上「顺转 d」与「转 360−d」互为同一排列**（环序 `1 8 3 4 9 2 7 6` 的 5 步与 3 步是逆序对），
故该写法下飞盘与转盘的九星盘**恒等**，参数等于没生效。现已改为真飞宫：
- **转盘（排宫）**：八宫环刚性旋转一量，天盘干与九星**同步**，中五寄坤二（天禽恒居中宫）。
- **飞盘（飞宫）**：天盘干与九星同沿**洛书宫数序 1→2→…→9** 飞布（**含中五**），阳顺阴逆；
  八神亦改为**九神**（`符蛇阴合勾常雀地天` / `符蛇阴合虎常玄地天`，中宫亦受一神），
  与转盘的八神（八卦轮转、不入中）不同。

**索引基准**（调研 §7#7 点名「混用必错」）：飞盘的平移量起讫两端**都用坤二归一化后的宫位**；
若一端用中五、另一端用归一化宫位，会得到错位的平移量、使值符不落时干宫。
本实现已修为归一化口径，上表 9600/9600 即该不变式的实测。

**日家 `#27` 独立口径**：起局基准为**日干支**，三元由**日支**定
（子午卯酉上元、寅申巳亥中元、辰戌丑未下元），局数取当日节气的三元表；
**时柱不参与**，故同一日内局数恒定。实测同一时刻：
`#25 时家阴遁1局转盘·天心值符落4宫` / `#26 时家阴遁1局飞盘·天心值符落4宫` /
`#27 日家阴遁4局转盘·天英值符落7宫`。`#25–#29` 五法 essence **去重 5/5**。

**八神口径（调研 A10 指出「两种正统口径冲突，必须决策」）**：本模块**两派并陈不复择一**——
转盘用「值符螣蛇太阴六合**勾陈朱雀**九地九天」，飞盘用「值符螣蛇太阴六合**白虎玄武**九地九天」，
两者的名称与落宫都写进 `detail`，读者可依师承取用。
